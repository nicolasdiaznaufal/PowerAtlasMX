# PowerAtlasMx v2 (web/v2)

Second, separate web version. v1 (`web/index.html`) is frozen at tag `v1-deck-page` and keeps working at `http://localhost:8080/#pnl`.

## Run
```
cd web && python3 -m http.server 8080
open http://localhost:8080/v2/
```
No build step. Plain ES modules, plain CSS, no CDN. Fonts (Geist, OFL) and deck.gl are vendored.

## Data (regeneration note)
v2 reads the existing files under `web/data/` (`index.json`, `analysis/analysis_nodos.json`, `derived/*.json`). The `.gitignore` entry `data/`
also ignores `web/data/`, so a fresh clone has no data: regenerate with `web/tools/build_derived.py` and copy `data/analysis/*.json`
into `web/data/analysis/` (see `web/README.md`). Do not commit data files.

## Layout
- `index.html`, `main.js` (hash router), `config.js` (CONTACT_EMAIL)
- `assets/css/tokens.css` (single token source, read by `web/tests/contrast-v2.test.mjs`), `base.css`
- `assets/js/*.js` small modules (< 300 lines), `assets/icons/eclipse.svg` (generated by `assets/js/export-logo.mjs`)
- `assets/img/clients/manifest.json`: client logos supplied by REPSA; empty until provided. Never invent logos.

## Map (M2)
- deck.gl 9.4.0 vendored in `assets/vendor/deckgl/` (see its README); loaded lazily by `map-view.js`. No basemap tiles.
- `geo.js` converts `web/assets/geo/mx.json` to lon/lat GeoJSON with the file's own projection block (checked against known nodes in `web/tests/v2-geo.test.mjs`).
- `atlas.js` joins `data/index.json` (names, coordinates) with `analysis_nodos.json` (window `deck_2025_26`, config `tracker`, the only config in that file). Rank in region is derived at load.
- Selection (max 3, any mix of node/state/region/national) lives in the hash: `#/map?sel=01AAN-85,state:JALISCO,national`.
- Without WebGL the map is replaced by a message; the selector and chips keep working.

## Flow (M3)
- Routes: `#/` landing, `#/map`, `#/choose`, `#/explorer`, `#/revenue`; selection in `?sel=` on every route; routes that need a selection redirect to `#/map`.
- `assets/js/shell.js` owns the ONE map host (`#maphost`): hidden / full / mini. Views only attach overlays; the canvas is never remounted.
- Page swaps use `document.startViewTransition` (the map host has its own transition name so it morphs full to mini card); without it, or with reduced motion, swaps are instant or a plain fade.
- Landing to map: the hero sun scales up and fades while the map fades in beneath.
- `assets/img/hero-sun.webp` is cropped from the 1x design mock (headline pixels retouched out). A clean full-resolution photo is needed for retina.
