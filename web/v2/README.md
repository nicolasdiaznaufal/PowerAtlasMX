# PowerAtlasMx v2 (web/v2)

Second, separate web version. v1 (`web/index.html`) is frozen at tag `v1-deck-page` and keeps working at `http://localhost:8080/#pnl`.

## Run
```
cd web && python3 -m http.server 8080
open http://localhost:8080/v2/
```
No build step. Plain ES modules, plain CSS, no CDN. Fonts (Geist, OFL) and deck.gl are vendored.

## Data (regeneration note)
v2 reads the existing files under `web/data/` (`index.json`, `analysis/analysis_nodos.json`, `derived/*.json`). The `.gitignore` entry `data/`
also ignores `web/data/`, so a fresh clone has no data: regenerate with `web/tools/build_derived.py` and copy `data/analysis/*.json`
into `web/data/analysis/` (see `web/README.md`). Do not commit data files.

## Layout
- `index.html`, `main.js` (hash router), `config.js` (CONTACT_EMAIL)
- `assets/css/tokens.css` (single token source, read by `web/tests/contrast-v2.test.mjs`), `base.css`
- `assets/js/*.js` small modules (< 300 lines), `assets/icons/eclipse.svg` (generated by `assets/js/export-logo.mjs`)
- `assets/img/clients/manifest.json`: client logos supplied by REPSA; empty until provided. Never invent logos.
